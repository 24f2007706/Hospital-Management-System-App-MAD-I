# 🏥 Hospital Management System

A comprehensive Hospital Management System built using Flask and SQLite to streamline hospital operations through a centralized web-based platform. The application enables efficient management of patients, doctors, appointments, and medical records while providing an intuitive user experience for healthcare administration.

## 🚀 Features

* Patient registration and profile management
* Doctor management and scheduling
* Appointment booking and tracking
* Medical record management
* CRUD operations for all major entities
* Secure database integration with SQLite
* Responsive and user-friendly interface
* Role-based workflow for hospital administration

## 🛠️ Tech Stack

* **Backend:** Flask, Python
* **Database:** SQLite
* **Frontend:** HTML, CSS, JavaScript
* **Templating Engine:** Jinja2
* **ORM:** SQLAlchemy

## 🎯 Project Objectives

The primary objective of this project is to digitize and automate hospital administration processes, reducing manual effort and improving operational efficiency. The system provides a structured workflow for managing healthcare-related information and enhances accessibility to patient and appointment data.

## 📌 Key Highlights

* Developed using the MVC architecture pattern
* Database-driven application with persistent storage
* Modular and scalable code structure
* Real-world healthcare management use case
* Clean and maintainable user interface
